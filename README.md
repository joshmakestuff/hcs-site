# hcs-site

Source for [joshmakestuff.github.io/hcs-site](https://joshmakestuff.github.io/hcs-site) —
the site for [hcsctl](https://github.com/joshmakestuff/hcsctl) and
[AspireHcs](https://github.com/joshmakestuff/AspireHcs).

Jekyll, built by GitHub Pages on push to `main`. No local toolchain required: edit the
`.md` files, push, and the site rebuilds in about a minute.
